The constraint that shaped everything

Every component must be free of charge and legally usable inside a closed-source commercial product. That single rule decided the architecture.

The original models were trained with Ultralytics YOLO. Their licence is AGPL-3.0, and it explicitly covers “the training code and the models produced by that training code.” Exporting to ONNX does not escape it. Distributing an AGPL work entitles every recipient to the complete source of the whole application — incompatible with selling a closed-source VMS.

Everything was rebuilt on RF-DETR (Apache-2.0) running on onnxruntime (MIT), with supervision ByteTrack (MIT) for tracking. The verified chain:

Licences were read from the source that actually serves the file — the Roboflow API, the HuggingFace card, the GitHub LICENSE. A mirror cannot grant a licence it does not hold, and a re-upload can lose or invent one. This cut both ways: one dataset was wrongly excluded because a HuggingFace mirror degraded “CC BY 4.0” to an ambiguous “cc”, and another was correctly rejected despite a plausible claim, because the copy in hand declared nothing.

Face Recognition auraface_glintr100.onnx + yunet Shipping

No training required. YuNet detects faces; AuraFace produces an embedding compared against an enrolled gallery by threshold, not softmax — which is what makes “unknown” a structurally possible answer rather than a nearest-match guess.

Face images are biometric personal data under India’s DPDP Act 2023. Every snapshot view is written to the audit trail, and embeddings are never stored in it.

Fire & Smoke trained, not deployed Do not ship

Trained for 9.5 hours and reached mAP@50 0.574. Fire precision 0.65 means about one in three alerts is false; smoke recall 0.47 means it misses over half of all smoke — and smoke is the early-warning half of the feature.

The cause was found by auditing the data afterwards: one source supplied 92% of the merged images and was 43% duplicate or near-duplicate — pre-augmented. RF-DETR augments during training, so the model largely learned that source’s augmentation.

Why more data alone will not fix this

In object detection, every unlabelled region trains as background. Merging a dataset that labels helmets but not bare heads teaches the model “bare head = background” — actively damaging no_helmet while improving helmet, which is already strong.

Only sources that annotate missing PPE under a compatible taxonomy can be merged. Three such datasets were located and verified; none of them annotate missing boots at all.

Platform

The models are one part. The machinery around them is what makes it sellable to more than one client at a time.

Multi-tenancy and licensing

  • Per-feature licensing. 26 features across 7 modules. A client buying intrusion does not receive the other six behaviours the same person worker provides.
  • Tenant isolation proven by 29 tests against real Postgres, with two clients sharing one server and one worker.
  • Per-org ingest tokens, SHA-256 stored. Rotation is the revocation path and clears every cache immediately.

Security

  • Session fixation fixed — proven real by removing the fix and watching three tests fail, then restoring it.
  • CSRF origin checking, because SameSite=lax compares the registrable domain and gives no protection between sibling subdomains.
  • Audit trail — append-only, records who viewed which footage, with secrets scrubbed on the way in.
  • AES-256-GCM camera credentials at rest; 30-day rolling sessions with a hard 90-day cap.

Operations

  • Disk monitoring with client-admin alerts before recording fails.
  • Schema drift check at boot, naming the exact missing table and the migration that creates it.
  • Backup and restore, both tested against a live database.
  • Sensor telemetry — parking, tank level, water pH, diesel theft detection. A dead sensor reads unknown, never “vacant”.
  • Location hierarchy — group → site → building → floor → zone, with cycle prevention and no silent orphaning of cameras.

Outstanding

Stated plainly, because a handover that hides these is worse than one that names them.

Blocking a sale

  • ANPR — never built, and it was the first thing asked for. Plate detection has ~29,000 CC BY 4.0 images ready; OCR for Indian plates is the real project.
  • Alerts never leave the browser — no email, SMS or push. A fuel-theft alert at 2 a.m. currently reaches nobody.
  • No reports — clients renew on monthly compliance and utilisation PDFs.

Unknowns that affect quoting

  • No load test. Cameras-per-box is still unknown.
  • CPU inference is 300–640 ms/frame. A site without a GPU cannot run these at 10 fps.
  • Never tested against a real camera — only a synthetic RTSP stream.
Process change

The fire model failed because licence and image count were verified while data quality was not. scripts/audit_dataset.py now checks duplicate rate, source dominance, box-size distribution, class balance, malformed annotations and train/val leakage — and is run before any GPU time is spent. A ten-hour run cannot repair a dataset.
